## 🚀 Getting Started

### Prerequisites
- A modern web browser
- (Optional) A local development server or hosting platform

### Installation

1. Clone the repository:
```bash
git clone https://github.com/qiuliangalexander-cmd/manekineko.be.git
cd manekineko.be
```

2. Open the website locally:
   - Simply open `index.html` in your web browser, or
   - Use a local server (Python, Node.js, etc.)

### Using a Local Server (Optional)

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

**Node.js (with http-server):**
```bash
npx http-server
```

Then visit `http://localhost:8000` in your browser.

## 🛠️ Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #d4af37;      /* Gold accent */
    --secondary-color: #1a1a1a;    /* Dark background */
    --accent-color: #667eea;       /* Purple accent */
    --text-color: #333;            /* Text color */
    /* ... other variables ... */
}
```

### Fonts
The website uses Google Fonts:
- **Playfair Display** - For titles and headings
- **Poppins** - For body text and UI elements

### Content
Edit content directly in `index.html`. Each section has clear ID attributes for easy identification.
